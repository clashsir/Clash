## 最小可用集

不必一次装齐。多数人按下面四条就能跑通日常：

| 角色 | 精选 | 一句话 |
|------|------|--------|
| 桌面主力 | [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/releases) | 维护活跃、资料多，Windows / macOS / Linux 首选之一 |
| macOS 菜单栏 | [ClashX Meta](https://github.com/MetaCubeX/ClashX.Meta/releases) | 轻、常驻菜单栏；要完整桌面窗体再看 Verge Rev / Party |
| Android | [Clash Meta for Android](https://github.com/MetaCubeX/ClashMetaForAndroid/releases) | Meta 系安卓常青树；原 Clash for Android 已停更 |
| 跨端一把梭 | [Clash Mi](https://github.com/KaringX/clashmi/releases) 或 [Hiddify](https://github.com/hiddify/hiddify-app/releases) | 同一订阅要在多系统复用时再上这两款 |

装完：**更新订阅 → 测延迟 → 再开系统代理 / TUN**。同一时间只开一个图形客户端，避免抢代理。

## 精选短评 · 维护中

每条卡片格式固定：**短评** → 平台 → Releases → 站内教程。按「桌面 → 移动 → 多内核」大致排序，不是热度榜。

> **Clash Verge Rev** · 桌面常青树  
> 短评：功能完整、社区讨论多，适合把旧 Clash for Windows 迁过来当主力。  
> 平台：Windows · macOS · Linux  
> 下载：[GitHub Releases](https://github.com/clash-verge-rev/clash-verge-rev/releases)  
> 教程：[clashsir.com/clash-verge](https://clashsir.com/clash-verge/)

> **Clash Party** · Mihomo 桌面新面孔  
> 短评：界面更轻、跟 Mihomo 生态贴得近；想换新鲜桌面壳可以试，和 Verge Rev 二选一即可。  
> 平台：Windows · macOS · Linux  
> 下载：[GitHub Releases](https://github.com/mihomo-party-org/clash-party/releases)  
> 教程：[clashsir.com/clash-party](https://clashsir.com/clash-party/)

> **FlClash** · 桌面 + Android 同系  
> 短评：Flutter 跨端，桌面和安卓体验接近；嫌客户端碎片太多时，可以桌面 / 手机都押这一款。  
> 平台：Windows · macOS · Linux · Android  
> 下载：[GitHub Releases](https://github.com/chen08209/FlClash/releases)  
> 教程：[clashsir.com/flclash](https://clashsir.com/flclash/)

> **Clash Nyanpasu** · 另一路桌面壳  
> 短评：功能向 Verge 系靠拢，适合已经熟悉 Nyanpasu 工作流的人；新人优先 Verge Rev 也没问题。  
> 平台：Windows · macOS · Linux  
> 下载：[GitHub Releases](https://github.com/LibNyanpasu/clash-nyanpasu/releases)  
> 教程：[clashsir.com/clash-nyanpasu](https://clashsir.com/clash-nyanpasu/)

> **ClashX Meta** · macOS 菜单栏专精  
> 短评：不抢 Dock、适合「开了就忘」；需要复杂覆写和仪表盘时再上完整桌面客户端。  
> 平台：macOS  
> 下载：[GitHub Releases](https://github.com/MetaCubeX/ClashX.Meta/releases)  
> 教程：[clashsir.com/clashx-meta](https://clashsir.com/clashx-meta/)

> **Clash Meta for Android** · 安卓 Meta 标配  
> 短评：订阅、分流、TUN 资料齐全；别再搜已停更的原版 Clash for Android 安装包。  
> 平台：Android  
> 下载：[GitHub Releases](https://github.com/MetaCubeX/ClashMetaForAndroid/releases)  
> 教程：[clashsir.com/clash-meta-for-android](https://clashsir.com/clash-meta-for-android/)

> **Clash Mi** · 少有的全平台 GUI  
> 短评：桌面 + iOS + Android 都想统一时优先看它；iOS 侧以当期商店 / 官方说明为准。  
> 平台：Windows · macOS · Linux · iOS · Android  
> 下载：[GitHub Releases](https://github.com/KaringX/clashmi/releases)  
> 教程：[clashsir.com/clash-mi](https://clashsir.com/clash-mi/)

> **Hiddify** · 多内核万金油  
> 短评：不止 Clash / Mihomo，还覆盖 sing-box 等；协议杂、设备多时很省事，界面也更偏「全家桶」。  
> 平台：Windows · macOS · Linux · iOS · Android  
> 下载：[GitHub Releases](https://github.com/hiddify/hiddify-app/releases)  
> 教程：[clashsir.com/hiddify](https://clashsir.com/hiddify/)

## 使用约定（精简）

1. **只认 Releases**：安装包来自各项目 GitHub Releases 或本页标明的备份仓，不认网盘「整合包」。  
2. **一个代理壳**：同时开多个 GUI 抢系统代理 / TUN，是最常见的「明明连上却打不开」原因。  
3. **订阅另算**：延迟高、流媒体失败，先换节点或订阅，再怀疑客户端。  
4. **架构别下错**：Windows 看 x64 / arm64；macOS 看 Intel / Apple Silicon；Android 看 abi。  
5. **本仓定位**：中文下载与教程分享索引，不是 Clash 官方开发组仓库。
